# EIP 商业计划书 · 移动端适配版

黑色极简风（纯黑 + 荧光柠绿 #cdf030）单文件 HTML 商业计划书，20 页。

**在线阅读**：https://maiajosias610-oss.github.io/eip-deck/

## 特性

- 单文件 HTML，全部图片 Base64 内嵌，双击即可离线打开
- 宽屏（> 900px）：固定 16:9 舞台，键盘 ←/→、滚轮、触摸滑动翻页
- 窄屏（≤ 900px，手机竖屏）：自动切换为「竖屏重排 + 纵向滚动」模式
  - 多列栅格自动降为单列/双列，横向流程改为堆叠
  - 技术架构图与数据表包在横向滚动容器中，可左右滑动查看
  - 顶部阅读进度条 + 右下角页码指示
- 旋转手机横竖屏自动切换布局模式

## 使用

直接打开 `index.html`，或部署到任意静态托管（GitHub Pages / Vercel / 对象存储）。

导出 PPTX 可配合无头浏览器逐页截图（见 black-minimal-deck 项目中的 render_pptx.py）。
